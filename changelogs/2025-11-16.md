## 🏗️ Core Infrastructure

### Blockchain Foundation
**Files:** `block.rs`, `chain.rs`, `tx.rs`, `main.rs`

#### Implemented Features:
- **Block Structure** (`block.rs`):
  - 64-bit index tracking
  - RFC3339 timestamps via Chrono
  - Transaction batch storage
  - SHA-256 hash calculation
  - Proof-of-Work mining with configurable difficulty
  - Hash linkage to previous block

- **Blockchain** (`chain.rs`):
  - Genesis block auto-generation
  - Chain validation (hash integrity + linkage verification)
  - Pending transaction pool
  - Mining rewards (1.0 coin per block)
  - JSON persistence (save/load from disk)

- **Transactions** (`tx.rs`):
  - Simple sender/recipient/amount model
  - String-based addresses (pending cryptographic upgrade)

- **Interactive CLI** (`main.rs`):
  - 7-option menu system
  - Add transactions, mine blocks, view chain
  - Validate blockchain integrity
  - Persist/restore blockchain state

### 4. Address Derivation System (`crypto/address.rs`)
**Lines:** 171 | **Tests:** 5/5 passing

#### Features:

**NetworkId Enum:**
- Mainnet (0x00)
- Testnet (0x6F)

**Address Structure:**
- Fixed 26-byte format:
  - 1 byte: Network ID
  - 1 byte: Algorithm ID
  - 20 bytes: Hash160 payload (SHA-256 → RIPEMD-160)
  - 4 bytes: Double SHA-256 checksum
- Base58 encoding for human readability

**API:**
- `derive()` from PublicKey + NetworkId
- `to_string()` / `from_str()` encoding
- `network()` / `algorithm()` / `payload()` extractors

**AddressError Types:**
- InvalidChecksum, InvalidLength
- InvalidNetwork, InvalidAlgorithm

#### Test Coverage:
- ✅ Mainnet derivation round-trip
- ✅ Short payload rejection
- ✅ Network/algorithm byte validation
- ✅ Hash determinism verification
- ⚠️ Checksum corruption test (documented gap, pending Base58Check)
